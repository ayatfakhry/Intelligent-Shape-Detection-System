# 🧠 Intelligent Shape Detection System

## 📌 Overview

This project focuses on detecting and classifying geometric shapes using computer vision techniques.

It compares classical image processing methods with AI-based models to evaluate performance and accuracy.

---

## 🚀 Features

* Shape detection (circle, triangle, square, rectangle, pentagon)
* AI-based classification
* Confidence scoring
* Classical vs AI comparison
* Evaluation metrics analysis

---

## ⚙️ Technologies

* Python
* OpenCV
* Scikit-learn
* NumPy
* Matplotlib

---

## 📊 Results

The system successfully detects multiple shapes with high confidence scores.

Example metrics include:

* Detection counts per shape
* Average confidence per class
* Maximum and minimum confidence values
